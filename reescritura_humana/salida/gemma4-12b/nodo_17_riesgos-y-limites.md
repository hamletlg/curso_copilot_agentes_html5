Copilot tiene límites importantes que debes conocer:

**Las alucinaciones existen**
Copilot puede generar datos, citas o hechos incorrectos. Esto ocurre porque el modelo de IA produce información que parece lógica pero es falsa basándose en patrones estadísticos. Verifica siempre los datos concretos.

**Los sesgos se transmiten**
El modelo puede repetir sesgos de género, culturales o económicos presentes en sus datos de entrenamiento. Un agente que resume noticias podría priorizar ciertos puntos de vista sobre otros.

**La privacidad depende de tu empresa**
Copilot de Trabajo sigue las políticas de seguridad y protección de datos de Microsoft 365. Tus datos no se usan para entrenar modelos, pero debes cumplir las normas de tu organización y no compartir información restringida.

**Los agentes no procesan como humanos**
Copilot procesa palabras como "banco" sin distinguir necesariamente si te refieres a una entidad financiera o a una orilla de río. El contexto ayuda a precisar el resultado, pero el sistema puede fallar.

**Depender demasiado es un riesgo**
Delegar todas las tareas a Copilot puede afectar tus habilidades propias. Si el sistema falla, es importante que sepas seguir trabajando sin él. Usa Copilot para mejorar tu rendimiento, no para sustituir tus funciones.

**Los agentes no tienen criterio ético**
Copilot no evalúa las implicaciones éticas de las peticiones. Si le pides realizar una tarea incorrecta, la ejecutará sin cuestionarla. Eres el responsable final de los resultados que genere la herramienta.

**Gobernanza corporativa**
Si tu empresa utiliza Agent Builder o Copilot Studio para crear agentes, existen controles de TI que determinan qué agentes se pueden publicar, con quién se comparten y a qué datos pueden acceder. Debes respetar estos controles.
